## Descrição
Aplicação web com visual de terminal retrô que consulta a PokeAPI e mostra dados completos de qualquer Pokémon: imagem, tipos, altura, peso, habilidades e estatísticas base. Útil para consultas rápidas ou apenas para se divertir descobrindo Pokémon aleatórios.

## API utilizada
- Nome da API: [PokeAPI](https://pokeapi.co/)
- Documentação: https://pokeapi.co/docs/v2
- Endpoint(s) consumido(s): `GET https://pokeapi.co/api/v2/pokemon/{nome-ou-numero}`

## Funcionalidades
- Buscar um Pokémon pelo nome ou número (campo de texto + botão "Buscar")
- Buscar um Pokémon aleatório com um clique (botão "Aleatório")
- Visualizar imagem oficial, número, tipos (com cor própria), altura, peso, habilidades e estatísticas base (em barras)
- Receber mensagens amigáveis quando o Pokémon não é encontrado ou a API está indisponível

## Como executar localmente

2. Abra o arquivo `index.html` no navegador
